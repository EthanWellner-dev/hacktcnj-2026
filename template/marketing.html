01 // The Inspiration

Why This Matters.

A whole generation grew up hyper-connected yet profoundly disconnected. We can debug code in milliseconds, but we can't read a room. That changes today.

We debug code flawlessly...

IDEs, linters, test suites. We have tools for everything digital.

...but not human connection.

Until now. Social Sandbox is the debugger for your communication skills.

Your Trainer

Social Sandbox isn't a boring corporate training. It's real. Stressful. Effective. You'll practice in safe, judgment-free scenarios powered by multimodal AI.

8 modules. 3 gyms. Infinite possibilities to become a better communicator.

02 // Official Module Directory

Three Pillars.
Eight High-Stakes Scenarios.

Users earn XP by completing modules, unlocking higher-stakes scenarios as they level up.

GYM 1: The Digital Comm Suite

Focus: Asynchronous text communication and reading subtext.

MOD_01

Sarcasm Sweeper

A digital minefield. Scan pre-written group chats and flag messages that contain hidden passive-aggression, sarcasm, or underlying hostility.

MOD_02

The Icebreaker

First impressions matter. Initiate a cold text conversation with an AI stranger and establish a common interest within 5 messages.

MOD_03

Hint Hunter

Read the room. The AI starts dropping subtle cues that it wants to end the conversation. You must gracefully close the chat.

MOD_04

The Ping-Pong Protocol

Conversational stamina. Keep a chat alive for 6 turns. Dead-end replies or closed-ended questions lose XP.

GYM 2: The Vocal Sandbox

Focus: Real-time verbal communication and conflict de-escalation.

MOD_05

Tone Check (The De-Escalator)

UNLOCKED AT 5,000 XP

Pressure testing. Hold a button to verbally respond to a stressful, hostile prompt (e.g., an angry boss voiced by ElevenLabs). Set a firm boundary without losing your cool. Evaluates vocal tone, shakiness, and defensiveness.

MOD_06

The Pitch (Confidence Calibration)

Overcoming the stutter. Verbally introduce yourself or pitch an idea. The system tracks pauses, hesitations, and filler words ("um", "uh") to calculate a live Confidence Score.

GYM 3: The Facial Gym

Focus: Cognitive load, computer vision, and non-verbal cues.

MOD_07

The Emotion Matrix

A high-speed multimodal flashcard game. Users are shown complex human facial expressions paired with subtle, conflicting audio cues (e.g., a smile paired with a frustrated sigh). Quickly identify the correct underlying emotion combining both visual and auditory subtext.

MOD_08

The Masking Mirror

Situational facial control. Given a scenario ("Listen to your coworker's boring story"), use your webcam to physically hold the socially appropriate expression (e.g., "Neutral/Attentive") for 3 continuous seconds without your face dropping.

03 // System Architecture

How We Built It

A highly scalable, modular architecture built from the ground up in just a few hours.

Frontend

  • Built with Vue.js and Tailwind CSS.
  • Custom "Glassmorphism / Cyber-Corporate" UI.
  • UI driven by a master JSON configuration object, allowing instant swapping of rulesets without rewriting components.

Backend & DB

  • Powered by MongoDB Atlas.
  • Stores user profiles, XP, and detailed session logs.
  • Flask for backend logic and Jinja for dynamic rendering.

The AI Brain

  • Gemini API: Parses subtext, returns structured JSON feedback, and analyzes raw .webm audio blobs to judge vocal inflection.
  • ElevenLabs: Custom antagonist voices with tweaked stability and similarity_boost parameters for realistic aggression.

Challenges Overcome

The Web Speech API State

Struggled with InvalidStateError crashes from rapid mic clicks. Built a bulletproof state-tracking wrapper using try/catch blocks around browser async audio engines.

Audio Blob Routing

Capturing raw audio via MediaRecorder and precisely formatting MIME-types for Gemini's native multimodal audio endpoints required intense data handling.

The Hackathon Clock

Went from ideation at 12:00 PM to 8 fully functional, highly polished UI modules mapped to complex logic by 7:00 AM. Scope management was critical.

Accomplishments

The Vue.js Config Pattern

Gym 1 is infinitely scalable. We can add 100 new text scenarios simply by adding JSON objects. The frontend dynamically adapts inputs based on config.

Zero-Latency Multimodal

For Module 7, we pre-generated ElevenLabs audio and coupled it with static images to test multimodal perception blazingly fast without live LLM delays.

Actionable, Diagnostic Feedback

Our LLM prompts are perfectly tuned. It doesn't just say "Good job," it says: "Threat neutralized. 'No rush' combined with 'biggest client' indicates passive-aggression."

04 // Retrospective

What We Learned

We learned how powerful native audio processing is compared to standard Speech-to-Text. Hearing the "shake" in a voice changes the entire context.

We mastered handling complex state management in Vue.js for real-time applications involving asynchronous browser APIs.

We learned that designing "stressful" UX requires a delicate balance of gamification (neon colors, XP bars) so the user feels challenged, not discouraged.
